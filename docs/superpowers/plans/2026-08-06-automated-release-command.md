# Automated Release Command Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one interactive, cross-platform command that selects a semantic version, validates and packages the CLI, tags the validated commit, and immediately publishes a verified GitHub release.

**Architecture:** A new `cmd/release` entry point delegates to a focused `internal/release` package. The package isolates semantic versions, terminal prompting, external process execution, repository validation, artifact validation, and publication behind testable boundaries while reusing the existing PowerShell and Bash artifact scripts.

**Tech Stack:** Go 1.26.5 standard library, Git, GitHub CLI, PowerShell, Bash, existing Go and shell test suites.

## Global Constraints

- The user-facing command is exactly `go run ./cmd/release`.
- The command is interactive-only and requires a final affirmative confirmation before any remote mutation.
- Stable versions use canonical `vMAJOR.MINOR.PATCH` syntax; prerelease and build metadata are rejected.
- Version choices are patch, minor, major, custom, and cancel.
- The command runs on Windows, Linux, and macOS; the release matrix remains Linux and Windows on amd64 and arm64.
- Release notes are generated by GitHub.
- Successful execution publishes immediately; the draft exists only while assets are uploaded and verified.
- Remote tags, releases, and assets are never automatically deleted or overwritten after a failure.
- Generated artifacts stay outside the repository and are preserved on failure.
- No GitHub Actions release workflow or non-interactive mode is added.

- [ ] **Step 3: Implement strict stable-version parsing and comparison**

```go
type Version struct { Major, Minor, Patch uint64 }
type Bump uint8

const (
	BumpPatch Bump = iota
	BumpMinor
	BumpMajor
)

var stablePattern = regexp.MustCompile(`^v(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)$`)

func ParseVersion(input string) (Version, error) {
	matches := stablePattern.FindStringSubmatch(input)
	if matches == nil { return Version{}, fmt.Errorf("version %q must match vMAJOR.MINOR.PATCH", input) }
	parts := [3]uint64{}
	for index := range parts {
		value, err := strconv.ParseUint(matches[index+1], 10, 64)
		if err != nil { return Version{}, fmt.Errorf("parse version %q: %w", input, err) }
		parts[index] = value
	}
	return Version{Major: parts[0], Minor: parts[1], Patch: parts[2]}, nil
}
func (v Version) String() string { return fmt.Sprintf("v%d.%d.%d", v.Major, v.Minor, v.Patch) }
func (v Version) Compare(other Version) int {
	left, right := [3]uint64{v.Major, v.Minor, v.Patch}, [3]uint64{other.Major, other.Minor, other.Patch}
	for index := range left {
		if left[index] < right[index] { return -1 }
		if left[index] > right[index] { return 1 }
	}
	return 0
}
func (v Version) Next(bump Bump) (Version, error) {
	switch bump {
	case BumpPatch:
		if v.Patch == math.MaxUint64 { return Version{}, errors.New("patch version overflow") }
		v.Patch++
	case BumpMinor:
		if v.Minor == math.MaxUint64 { return Version{}, errors.New("minor version overflow") }
		v.Minor++; v.Patch = 0
	case BumpMajor:
		if v.Major == math.MaxUint64 { return Version{}, errors.New("major version overflow") }
		v.Major++; v.Minor, v.Patch = 0, 0
	default:
		return Version{}, fmt.Errorf("unknown version bump %d", bump)
	}
	return v, nil
}
func LatestVersion(tags []string) Version {
	latest := Version{}
	for _, tag := range tags {
		candidate, err := ParseVersion(tag)
		if err == nil && candidate.Compare(latest) > 0 { latest = candidate }
	}
	return latest
}
```

Use `errors`, `fmt`, `math`, `regexp`, and `strconv` from the standard library.

type Prompter struct {

`SelectVersion` repeatedly reads a trimmed line, maps `1`, `2`, and `3` to the calculated versions, asks for a custom version after `4`, and returns `ErrCancelled` for `5` or end-of-file.
