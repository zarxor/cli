Install jb

Use a one-line quick install, or download and review the bootstrap script first. Both installers verify the released archive and checksum before installing.

Linux

Debian · Ubuntu · Arch

For Debian/Ubuntu and Arch Linux. The default installation is user-local and does not need root access.

One-line install

curl -fsSL https://cli.johanbostrom.se/install.sh | bash

Prefer to review first? Download install.sh, then run bash install.sh.

Windows

PowerShell

For Windows PowerShell. The default installation is in the current user's local application data.

One-line install

Invoke-RestMethod https://cli.johanbostrom.se/install.ps1 | Invoke-Expression

Prefer to review first? Download install.ps1, then run .\install.ps1.

Install and update tools

Plans are shown before changes are made. Add --yes for automation or --dry-run to inspect a plan without changing your machine.

Install supported tools

interactive

Open the interactive list with every not-yet-installed eligible tool preselected. Already installed tools are grayed out with their detected version and cannot be selected; use jb tools update to update them. Use ↑/↓ to move, Space to toggle, Enter to accept, or Escape/Ctrl+C to cancel safely.

jb tools install

Redirected input uses a plain numbered fallback. Set NO_COLOR to disable terminal colors; symbols keep the state readable.

Automate installation

automation

Install the complete supported catalog without selection or confirmation prompts.

jb tools install --yes

Development profile

profile

Select the built-in development toolchain explicitly.

jb tools install --profiles=development

Choose a tool

focused

Narrow a profile while retaining the dependencies it needs.

jb tools install --profiles=development --only=bun

Update installed tools

refresh

Discover installed tools and their versions live, then update only what is already installed.

jb tools update

Update a profile selection

focused

Narrow the profile to Bun and its required dependencies; only installed members are updated.

jb tools update --profiles=development --only=bun

Privileges stay deliberate

Each adapter uses the native package manager and requests elevation only for actions that require it. macOS support is planned for a future release.

Debian/Ubuntu
Uses supported apt repositories and sudo only for system package operations.
Arch Linux
Uses full pacman transactions with the same limited privilege boundary.
Windows
Uses per-user package operations where possible; machine-wide actions request elevation.
macOS
Planned for the future; not supported by the initial release.
