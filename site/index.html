Install jb

Download the installer, review it, then run it. Installers verify the released archive and checksum before installing.

Linux

For Debian/Ubuntu and Arch Linux. The default installation is user-local and does not need root access.

Download install.sh 
curl -fsSLO https://cli.johanbostrom.se/install.sh
less install.sh
bash install.sh

Windows

For Windows PowerShell. The default installation is in the current user's local application data.

Download install.ps1 
Invoke-WebRequest https://cli.johanbostrom.se/install.ps1 -OutFile install.ps1
Get-Content .\install.ps1
.\install.ps1

Install and update tools

Plans are shown before changes are made. Add --yes for automation or --dry-run to inspect a plan without changing your machine.

Development profile

Install the supported development toolchain.

jb tools install --profiles=development

Choose a tool

Narrow a profile while retaining the dependencies it needs.

jb tools install --profiles=development --only=bun

Update installed tools

Discover installed tools and their versions live, then update only what is already installed.

jb tools update

Update a profile selection

Narrow the profile to Bun and its required dependencies; only installed members are updated.

jb tools update --profiles=development --only=bun

Development tool catalog

The built-in development profile resolves dependencies and deduplicates shared tools before showing the plan.

  • Git

  • npm, Corepack, pnpm, and Yarn
  • Codex and Bun

Privileges stay deliberate

Each adapter uses the native package manager and requests elevation only for actions that require it. macOS support is planned for a future release.

Debian/Ubuntu
Uses supported apt repositories and sudo only for system package operations.
Arch Linux
Uses full pacman transactions with the same limited privilege boundary.
Windows
Uses per-user package operations where possible; machine-wide actions request elevation.
macOS
Planned for the future; not supported by the initial release.
