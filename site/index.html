Start with the installer that fits your shell.

Choose a platform, copy the quick install, or download the bootstrap script to review it first. Go is not required on the target machine.

INSTALLER / ENTRY POINTREVIEWABLE BY DEFAULT

Debian / Ubuntu / Arch

User-local by default, without root access.

LINUX / 01

One-line install

curl -fsSL https://cli.johanbostrom.se/install.sh | bash

Prefer to review first? Download install.sh, then run bash install.sh.

macOS with Homebrew

Supports Intel and Apple Silicon release binaries.

MACOS / 01

One-line install

curl -fsSL https://cli.johanbostrom.se/install.sh | bash

Install Homebrew first when using the macOS tool adapter. Download install.sh to review the bootstrap.

Windows PowerShell

Installs in the current user's local application data by default.

WINDOWS / 01

One-line install

Invoke-RestMethod https://cli.johanbostrom.se/install.ps1 | Invoke-Expression

Prefer to review first? Download install.ps1, then run .\install.ps1.

WHAT HAPPENS NEXT
  1. 1
    Download

    The bootstrap selects the current release for your OS and CPU.

  2. 2
    Verify

    The archive and its adjacent checksum must agree before install.

  3. 3
    Run

    The installed binary prints the next shell action when PATH needs help.

Review the script before running it if that is your preferred path.

Keep the plan visible.

The command surface is small on purpose: install, update, narrow, preview, or extend with Agent Skills. Interactive by default; ready for automation when you need it.

jb tools installinteractive

Detect whether the host is a desktop or server, apply the matching profile, then open the supported catalog with eligible tools preselected.

jb tools install

Interactive lists preselect eligible tools, keep installed tools visible, and use numbered prompts when input is redirected. Use Space to toggle, ↑/↓ to move, and Enter to accept.

jb tools updaterefresh

Apply the detected desktop or server profile, discover live versions, and show only installed tools with an available update.

jb tools update
jb status / jb doctordiagnose

Inspect the host and toolchain, with JSON output for automation and a failing doctor result when selected tools need attention.

jb doctor --json
jb tools install --profiles=optionaloptional

Add mise, uv, and OpenCode on demand without changing the automatic desktop or server setup.

jb tools install --profiles=optional
jb tools install --profiles=development --only=bunscope

Narrow a profile while retaining Bun's required dependencies.

jb tools install --profiles=development --only=bun
jb tools update --profiles=development --only=bunscoped update

Narrow profile updates to installed Bun dependencies only.

jb tools update --profiles=development --only=bun

Narrow the profile to Bun and its required dependencies; only installed members are updated.

jb service installautostart

Install the T3 Code backend as a per-user Linux systemd service that starts at boot.

jb service install
jb service restart / logsrecovery

Restart the T3 Code user service or inspect its recent systemd journal when the backend needs recovery.

jb service restart
jb skills installextend

Choose scope and Codex or Claude destinations first, then select grouped skills from the explicit catalog.

jb skills install
jb skills updatemanaged

Scan both scopes and supported harnesses with progress feedback, showing only bundles whose content has changed.

jb skills update --dry-run
jb updaterelease

Download the latest CLI release, verify its checksum, and replace the installed binary.

jb update
jb tools install --yesautomation

Apply the detected profile and install its eligible tools without selection or confirmation prompts.

jb tools install --yes
jb tools install --profiles=developmentprofile

Select a built-in profile explicitly; desktop, server, and development profiles are available.

jb tools install --profiles=development
--dry-runpreview

Append it to install or update to render the plan without changing the machine.

jb tools update --dry-run

Know what gets managed.

The development profile resolves dependencies from live machine state, then hands each tool to the provider that owns it.

PROVIDER BOUNDARIESPRIVILEGE / DELIBERATE
Debian/Ubuntu
Supported apt repositories; sudo only for system package operations.
Arch Linux
Full pacman transactions with the same limited privilege boundary.
Windows
Per-user package operations where possible; elevation only when required.
macOS
Homebrew-backed tools with user-level Node CLIs and native Intel/Apple Silicon binaries.
